# Wisdom Computers: logo and brand kit

## The mark
A **W** drawn as one continuous line, like a signal on a screen, with a **cursor pixel** at the top right.
Together the W and the pixel also read as **"wi"**: the dot of the *i* in wisdom.
Built on a 64-unit grid, so it stays sharp from a 16 px browser tab up to a shop signboard.

## Files
| File | Use it for |
|---|---|
| `logo-horizontal.svg` | Website header, letterhead, bills, email signature (light backgrounds) |

| `png/whatsapp-profile-640.png` | WhatsApp Business profile photo |

| `png/logo-horizontal-1200.png`, `png/logo-stacked-1000.png` | Word, Canva, anywhere SVG isn’t accepted |

SVGs are vectors: send these to the print shop for signboards and flex. The text is converted to outlines, so no font is needed.

## Type
**Geist** SemiBold for "wisdom" (lowercase, tight spacing) and Geist SemiBold for "COMPUTERS" (capitals, wide spacing). Free from vercel.com/font.

## Do / Don't
- Do keep clear space around the logo equal to the pixel’s width × 2.
- Do use the mono versions when only one ink colour is available.
- Don’t stretch, rotate, recolour the W, or add shadows or outlines.
- Don’t place the orange mark on an orange background; use the ink version there.
- Minimum size: mark 16 px on screen, 8 mm in print. Horizontal logo 120 px wide on screen, 30 mm in print.
